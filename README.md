## // Обо мне

Я соединяю практический опыт управления операционными и складскими процессами с разработкой цифровых решений. Поэтому начинаю не с инструмента, а с самой работы: где теряется время, дублируются действия, возникают ошибки и простаивают люди.

Развиваю **[CROND](https://crond.ru)** — небольшую студию автоматизации для малого и среднего бизнеса. Создаю решения, которые снимают рутину с сотрудников, работают круглосуточно и остаются понятными владельцу бизнеса.

- автоматизирую заявки, уведомления, документы и отчёты;
- связываю сайты, CRM, почту, таблицы и мессенджеры;
- внедряю ИИ для разбора обращений, извлечения данных и подготовки черновиков;
- создаю быстрые сайты вручную на HTML, CSS и JavaScript;
- настраиваю чат-ботов, CRM и сервисы онлайн-записи;
- улучшаю процессы с опорой на Lean, 5S и практику реальных операций.

## // Чем могу быть полезен

| Направление | Что получает бизнес |
|---|---|
| **Автоматизация** | Заявки, данные, задачи и уведомления движутся между системами без ручного переноса |
| **Интеграция ИИ** | ИИ классифицирует обращения, извлекает поля из документов, сжимает информацию и готовит черновики |
| **Сайты** | Быстрый адаптивный сайт без конструктора, связанный с формами, аналитикой и внутренними системами |
| **Чат-боты** | Приём заявок, ответы на частые вопросы и запись клиентов 24/7 |
| **CRM и онлайн-запись** | Единая воронка, автоматические задачи, напоминания и прозрачная история работы с клиентом |
| **Оптимизация процессов** | Меньше потерь, лишних действий и ошибок; понятные стандарты и визуальное управление |

## // Подход к работе

1. Разбираю процесс и нахожу реальную причину потерь.
2. Проектирую минимальное решение под одну измеримую задачу.
3. Запускаю MVP, проверяю его на живом процессе и только затем расширяю.
4. Передаю понятную систему, документацию и доступы владельцу.
5. Учитываю требования 152-ФЗ и размещение данных в российском контуре там, где это необходимо.
