## // Обо мне

Разбираю реальные процессы, нахожу потери и превращаю повторяющиеся операции в понятные цифровые решения. Развиваю **[CROND](https://crond.ru)** — проект по автоматизации малого и среднего бизнеса.

- **Оптимизация процессов:** Lean, 5S, стандарты и визуальное управление.
- **Автоматизация:** заявки, уведомления, документы и отчёты.
- **Интеграции и ИИ:** сайты, CRM, почта, таблицы и мессенджеры; обработка обращений и извлечение данных.
- **Веб-решения:** сайты, чат-боты, CRM и сервисы онлайн-записи.

## // Как работаю

`процесс → причина потерь → MVP → проверка на живой задаче → масштабирование`

Начинаю с одной измеримой задачи, передаю владельцу понятную систему и учитываю требования к размещению персональных данных.
